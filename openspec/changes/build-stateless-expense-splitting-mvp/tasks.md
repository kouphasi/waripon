## 1. ブラウザアプリケーションの基盤

- [x] 1.1 Viteによるブラウザビルド、テストランナー、CSV解析器、および必要なTypeScript設定とパッケージスクリプトを追加する。
- [x] 1.2 ユーザーデータ用エンドポイントや永続化バインディングを追加せず、本番のブラウザアセットを配信するようWranglerを設定する。
- [x] 1.3 レスポンシブな日本語アプリケーションシェルと、共通のフォーム、検証メッセージ、ダイアログ、テーブル、円表記のスタイルを作成する。

## 2. 正規状態と検証

- [x] 2.1 安定したIDの生成を含む、バージョン1の参加者、支払い、計算状態、導出差額、送金の型を定義する。
- [x] 2.2 名前、整数円金額、一意なID、相互参照、負担者一覧、端数調整担当者の不変条件に対する正規化と完全な状態検証を実装する。
- [x] 2.3 有効な状態、重複する名前とID、無効な金額、壊れた参照、空の負担者一覧、無効な担当者を対象とする単体テストを追加する。

## 3. 負担割り当てと精算エンジン

- [x] 3.1 正確な均等負担の集計と整数への切り捨てに使用する、約分済み `bigint` 有理数の補助処理を実装する。
- [x] 3.2 担当者以外の負担額を切り捨て、残額を選択した担当者へ割り当て、担当者の整数調整額を報告するグループ単位の負担割り当てを実装する。
- [x] 3.3 追加の丸めをせず、支払総額、差額、参加者順による決定的な貪欲法の送金を実装する。
- [x] 3.4 複数の支払いに対して、負担額合計の維持、差額合計が0であること、送金による完全な精算、決定性、境界条件を証明する具体例テストと不変条件テストを追加する。

## 4. 参加者と支払いの操作

- [x] 4.1 入力欄内の検証と安定した参照を備えた、参加者の追加、改名、参照中の削除防止を実装する。
- [x] 4.2 単一選択の端数調整担当者radioグループ、先頭参加者の初期選択、削除時のフォールバック、即時再計算を実装する。
- [x] 4.3 説明、整数円金額、1人の支払者、1人以上の負担者を扱う支払いの追加、編集、削除を実装し、新規支払いでは全参加者を初期選択する。
- [x] 4.4 参加者ごとの支払総額、割り当て負担額、差額、端数調整額、送金元から送金先への精算指示を、空状態と精算済み状態を含めて表示する。

## 5. CSVインポート

- [x] 5.1 定義済みヘッダー、引用符付きフィールド、BOM、パイプ区切りの負担者名に対応するUTF-8 CSV解析を実装する。
- [x] 5.2 解析済みファイルを、参加者が最初に出現した順序と、行番号付きで一括判定する検証エラーを持つ計算候補へ変換する。
- [x] 5.3 ファイル選択、エラー概要、参加者と支払いのプレビュー、キャンセル操作、確認後の一括置き換えフローを追加する。
- [x] 5.4 確認しやすいCSV形式のヘルプと、ダウンロードまたはコピー可能な有効なテンプレートを追加する。
- [x] 5.5 有効なインポート、引用符付き内容、BOM、空白除去、不正な構文、ヘッダー、行エラー、キャンセル、確認済み置き換えを対象とするCSVテストを追加する。

## 6. サーバーへ保存しないURL共有

- [x] 6.1 簡潔なバージョン付きJSONのシリアライズ、deflate圧縮、base64url変換、防御的なエンコード前後のサイズ制限を持つ `state` URLフラグメント変換処理を実装する。
- [x] 6.2 有効なバージョン1の状態、未対応バージョン、不正なデータ、検証失敗を区別し、状態を部分的に変更しない起動時復元処理を実装する。
- [x] 6.3 8,000文字の上限、ブラウザ機能の検出、プライバシー上の注意、コピー操作、解決方法を示すサイズ超過または未対応ブラウザのエラーを含む共有画面を追加する。
- [x] 6.4 決定的な往復変換、計算の復元、不正および過大なデータ、未対応バージョン、すべての導出結果が除外されていることを対象とするURLテストを追加する。
